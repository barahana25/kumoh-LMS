# 강의자료 자동 다운로드 (Android)

## 사용

1. 자동 로그인을 켜고 로그인한다.
2. 설정 → 저장 폴더 선택·만들기를 누른다.
3. Android 폴더 선택창에서 다운로드로 이동한다. 새 폴더 메뉴로 `2학년 2학기`를 만들거나 기존 폴더를 연 후 `이 폴더 사용`을 누른다. Android 11 이상에서는 다운로드 최상위 폴더 자체는 선택할 수 없으므로 하위 폴더를 선택한다.
4. 강의자료 자동 다운로드를 켠다. 처음 켤 때 현재 학기 자료를 다운로드하고, 이후에는 아직 저장하지 않은 파일만 받는다. `지금 다운로드`는 수동으로 실행한다.

저장 예: `Download/2학년 2학기/정치학입문-01 (5342)/1주차__12345.pdf`.
강의 ID와 파일 ID는 동명이 다른 강의·파일을 구분한다. 경로 문자와 위험한 이름을 정리한다. 같은 이름의 사용자 파일이 이미 있으면 번호를 붙이며 덮어쓰지 않는다.

## 동작

- 알림 설정과 별개로 켜고 끌 수 있다. 자동 조회 시간은 KST 00:01, 08:01~23:01이며 새벽 01:00~07:59는 쉰다. OS 절전 및 네트워크 상황에 따라 늦어질 수 있다.
- 저장 폴더 접근권한을 지속 보관한다. 권한 상실·폴더 삭제 시 일시 중지하고 폴더 재선택을 안내한다. 모든 파일 접근권한이나 미디어 권한을 추가하지 않는다.
- Android Storage Access Framework의 `ACTION_OPEN_DOCUMENT_TREE`, `takePersistableUriPermission`, `DocumentsContract`를 사용한다. 로컬 Flutter 플러그인 `packages/lms_folder_storage`라서 WorkManager의 별도 Flutter 엔진에도 자동 등록된다.
- 파일은 인증된 Canvas 세션으로 앱 캐시에 먼저 다운로드하고 선택한 트리 안에 임시 문서로 복사한 다음 최종 이름으로 바꾼다. 실패한 복사는 앱이 만든 임시 문서를 정리한다. 강제 프로세스 종료 직전에는 `.lms-*.part`가 남을 수 있으나 완료 파일로 기록하지 않는다.
- DB v5에 설정·실행 잠금·저장 완료 URI를 보관한다. 완료된 파일은 건너뛰고 사용자가 삭제했다면 다시 받는다. 전송 실패는 다음 조회에서 재시도한다. 실행 예산 약 4분을 넘는 전송은 취소하고 다음에 처음부터 재시도한다(바이트 단위 이어받기는 아님).
- 새 폴더를 선택하면 자동 다운로드는 꺼진다. 다시 켜면 그 폴더에 자료를 저장한다. 기존 폴더의 파일을 이동하거나 삭제하지 않는다.
- 로그아웃·계정 변경은 자동 다운로드와 기록을 정리하지만 사용자가 선택한 폴더의 파일은 보존한다. 모바일 데이터가 사용될 수 있다.
- iOS 폴더 북마크 기반 저장은 구현하지 않았다. 해당 설정은 Android에서만 표시한다.

## 검증

다운로드 회귀 테스트 9개: 최초 저장, 새 파일만 저장, 동일 이름 충돌 구분, 실패 재시도, 삭제 파일 재다운로드, 권한 상실, 계정 불일치, 다운로드 중 비활성화, 휴식/회차 제한, v4→v5 이관, 경로 이름 정리를 검증했다. 전체 282개 테스트 통과.
Android Java 플러그인 컴파일 및 GeneratedPluginRegistrant 등록 확인. 실제 학교 서버 PDF 155840바이트를 읽기 전용으로 받아 `%PDF-` 헤더를 검증하고 임시 파일을 제거했다. APK 빌드와 실제 기기의 폴더 선택/백그라운드 장시간 실행은 이번 작업에서 하지 않았다.

Android 공식 저장소 문서: https://developer.android.com/training/data-storage/shared/documents-files
